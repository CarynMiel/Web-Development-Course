Introducing HTML Tables

What are tables?

tables are structured sets of data, made pu of rows and columns. They can be a great way of displaying data clearly.

Early Usage

In the early days of the web, tables were commonly used to create page layous. Today, you should only use the table element when you are creating and actual data table.

In my oppinion this is most likely to not confuse screen readers and make the website more accessible.

Lots of Elements

To Create a table, you'll use 5-10 different elements! It can be tricky to remember them all, but don't panic!

Basic Table Practice
  • table tag
    • Creates a table
    • requires a tr child to be shown
    • Without css there is no borders and is just a way to create a grid of infomration
  • td tag
    • Table cell data
    • A child of the tr tag
  • tr tag
    • Table row
    • A child of the table tag
  • th tag
    • Table header tag
    • A child of the tr tag
    • A substitute for the td tag

Tables: Thead, Tbody, and Tfoot Elements

Elements

  • <table>
  • <td>
  • <tr>
  • <th>
  • <thead>
  • <tbody>
  • <tfoot>
  • <colgroup>
  • <caption>
Basic Table Practice

These elements are a way of just logically breaking up the table into sections to specify that one part of the table is the body, the header, and the footer.
They are also good for semantic HTML so that the table is also easier to read and easier to understand using a screen reader

  • thead element
    • Specifies that section is the head
    • The parent of a row
  • tbody element
    • Specifies the body section of the table
    • The parent of a row
  • tfoot element
    • Specifies teh foot of the table
    • the parent of a row
    • not usually used since most tables don't have a foot

Tables: Colspan and Rowspan

How to make tables with cells that span across multiple cells.
Merged cells that take up multiple rows or collums

Attributes

  • colspan="number"
    • Will take up number cells going left and right
  • rowspan="number"
    • Will take up number cells going up and down

Coding Exercise 5: Table Practice Exercise

It's time to get some practice with all those table-related elements! (yikes) Your goal is to create a 3x3 table, with proper headings. (so it's really 4x3 if you count the heading cells) I've provided you with some starter data in index.html, though you do not have to use it. Just make sure you create a 3x3 table with a row of headings at the top, using the correct semantic elements. You are expected to use the following elements: table, thead, tr, th, tbody, and td.

Code:

          
<table>
  <thead>
    <tr>
      <th>Subscription</th>
      <th>Price</th>
      <th>Support</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Free</td>
      <td>Free</td>
      <td>N/A</td>
    </tr>
    <tr>
      <td>Personal</td>
      <td>$9.99</td>
      <td>Weekdays</td>
    </tr>
    <tr>
      <td>Business</td>
      <td>$49.99</td>
      <td>24/7</td>
    </tr>
  </tbody>
</table>

Output:

          

            
                

                    Subscription
                    Price
                    Support
                

            
            
                

                    Free
                    Free
                    N/A
                

                

                    Personal
                    $9.99
                    Weekdays
                

                

                    Business
                    $49.99
                    24/7

The Form Element

Creating Forms

  • the <form> element itslef is a shell or container that doesn't have any visual impact.
    • Similar to the <table> element it the way that the element alone doesn't add thing but when you add children elements it shows something
  • we then fill the form with a collection of inputs, checkboxes, buttons, etc.
    • Smilar to the elements that go in the <table> element where the children of the element does the visuals and the parent just says what that section of code is

<form>

  • The form element- represents a document section containing interactive controls for submitting information.
  • The action attribute specifies WHERE the form data should be sent.
  • The method attribute specifies which HTTP method should be used (don't worry abou this for now)
